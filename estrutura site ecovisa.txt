O QUÊ É ESTE DOCUMENTO?
Um arquivo de referência central que documenta o estado completo do site da Ecovisa:
estrutura de navegação, conteúdo por página, componentes, imagens, funcionalidades e
lacunas. Ele serve como "single source of truth" entre o dev, o designer e o gerente
de produto.

PARA QUÊ SERVE?
- Análise rápida por IA (Claude): ao fornecer este arquivo, a IA entende exatamente
  o que existe, o que falta e onde fazer melhorias sem pedir para reler código HTML.
- Comunicação com o time: evita mal-entendidos sobre o que já foi feito vs. o que falta.
- Histórico de mudanças: quando você atualizar este arquivo, deixa claro o progresso.
- Base para prompts: cada novo prompt sobre o site pode referenciar as seções aqui.

COMO USAR?
1. Mantenha este arquivo SEMPRE ATUALIZADO quando fizer mudanças no site.
2. Antes de pedir à IA para melhorar algo, envie este arquivo junto com seu prompt.
3. A IA usará este documento para entender contexto sem reler HTML inteiro.
4. Versione: mude "VERSÃO VIVA" para "v1.0", "v1.1", etc. conforme evolui.
